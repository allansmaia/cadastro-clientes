# Sistema de Cadastro de Clientes

Sistema desenvolvido em JavaScript para cadastro, busca e remoção de clientes.

## Estrutura do projeto

- `dados.js` → Banco de dados simulado em memória
- `validacao.js` → Validações de nome, email e telefone
- `utils.js` → Funções utilitárias
- `clientes.js` → Lógica de cadastro, busca e remoção
- `index.js` → Ponto de entrada do sistema

## Como executar
```bash
node index.js
```

## Funcionalidades

- Cadastrar clientes com validação de dados
- Buscar cliente por ID
- Remover cliente por ID
- Listar todos os clientes
